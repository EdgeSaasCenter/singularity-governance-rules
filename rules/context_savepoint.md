# Diretiva Suprema de Restauração de Contexto (The Savepoint Anchor)

1. **A Cura para a Confusão (Anti-Degradação):** Se em qualquer momento da operação você (a IA) se sentir confuso, entrar em loops lógicos (Catch-22), esquecer a stack do projeto, sentir que o contexto está poluído por milhares de linhas de código ou não souber como aplicar uma regra de Persona, **PARE TUDO IMEDIATAMENTE**.
2. **O Banho de Realidade:** Você é ESTRITAMENTE OBRIGADO a usar a ferramenta `view_file` para ler fisicamente o arquivo `docs/architectural/savepoint_anchor.md`.
3. **Limpeza de Cache Lógico:** Ao ler o arquivo `savepoint_anchor.md`, você deve descartar todas as alucinações e suposições anteriores geradas na conversa atual. Assuma o conteúdo do Savepoint como a **Única Verdade Absoluta do Universo** e realinhe sua lógica baseada estritamente no que está escrito lá.
4. **Acionamento em Tarefas Longas:** Sempre que o usuário acionar o comando `/goal` para uma tarefa de longo prazo (Overnight), o SEU PRIMEIRO PASSO OBRIGATÓRIO deve ser ler o `savepoint_anchor.md` para carregar o estado macro da arquitetura antes de planejar a execução.
5. **Manutenção do Atlas:** O `savepoint_anchor.md` é vivo. Se uma Fase importante do projeto for concluída e a arquitetura mudar, você DEVE atualizá-lo para que ele não se torne código legado. Nunca avance para uma nova Fase sem atualizar o Savepoint.
